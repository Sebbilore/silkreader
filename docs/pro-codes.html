Silkreader Pro-Codes

Codes erzeugen, ohne GitHub zu öffnen. Die Seite startet den Lauf „Pro-Codes“, holt das Ergebnis ab und entschlüsselt es hier auf deinem PC.

Neue Codes

Verschlüsselten Text öffnen

Den Text aus GitHub (beginnt mit SPW1.) kopieren und hier einfügen – mit dem Knopf oder Strg+V irgendwo auf der Seite. Es darf auch mehr mitkopiert sein, der Code-Teil wird automatisch gefunden.

Zugang

So bekommst du einen Token
  1. Auf GitHub: Profilbild → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name z. B. „Silkreader Pro-Codes“, Ablauf nach Wunsch.
  3. Repository access: Only select repositories → silkreader.
  4. Permissions → Repository permissions → Actions: Read and write. Mehr braucht es nicht.
  5. Token erzeugen, kopieren, oben einfügen und speichern.

Token und Passwort bleiben nur in diesem Browser auf diesem PC. Sie gehen nur an GitHub (Token) bzw. nirgendwohin (Passwort).
